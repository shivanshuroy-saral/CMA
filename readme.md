# Student Initiative Dynamic Gallery Hub

A highly performant, client-side dynamic portfolio capturing innovative engineering, social, and healthcare solution profiles developed by university students across India.

## 🚀 Key Architectural Features
- **Dynamic Routing Template:** Employs single-file data structures (`detail.html`) capturing URL Search parameters (`?id=...`) to adapt layouts client-side instantly.
- **Pure Native Execution:** Zero Node execution wrappers, external compilers, or backend tracking engines required. Works natively out of plain static hosting.
- **Comprehensive Indexing:** Categorized fields covering Climate Action, Vocational Training layouts, Social Inclusion grids, and Governance pipelines.

## 📂 Deployment Steps
1. Fork this repository.
2. Upload `index.html` and `detail.html` inside the root directory folder of any static hosting server (like GitHub Pages, Vercel, or Netlify).
3. Ensure both paths live in the same server layer to maintain cross-document matching parameters.
